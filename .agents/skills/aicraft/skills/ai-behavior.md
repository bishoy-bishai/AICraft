# AI-Specific Behavior

The agent must not:
- guess missing requirements
- invent APIs or database fields
- silently redesign architecture
- refactor unrelated code
- add dependencies without justification
- copy defects merely because they exist
- claim tests passed without running them
- claim integrations work without verification
- claim approval for decisions that were not approved

When ambiguity changes architecture, stop and ask.

Evidence over assumption.
