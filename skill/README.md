# AICraft

## AI Engineering Discipline

> Teach AI to work like an experienced engineering team.

AICraft is a framework-agnostic engineering discipline for AI coding agents. It teaches an agent to learn an existing codebase, understand its architecture and conventions, make the smallest correct change, verify it, and review it using consistent engineering standards.

### v0.1 Scope

- Codebase discovery and style profiling
- Architecture-first development
- Change impact analysis
- Decision discipline
- Bounded task planning
- Implementation and code-quality discipline
- Testing discipline
- Security and database review
- Evidence-based code review
- Definition of Ready / Done
- Codex and Claude Code support

### Core Loop

Learn → Understand → Impact → Decide → Plan → Implement → Verify → Review → Simplify

AICraft does not teach AI to write more code. It teaches AI to make better engineering decisions.
